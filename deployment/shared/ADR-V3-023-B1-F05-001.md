# ADR-V3-023-B1-F05-001 — Separate Reference Evaluation Deployments

**Status:** APPROVED — ARCHITECTURE DECISION ONLY
**Decision date:** 2026-11-06
**Decision authority:** Technical Architecture Owner
**Scope:** V3-023 / Stage B1 / REFERENCE_ONLY
**Related finding:** B1-F05
**Implementation baseline:** cb4a865

## 1. Context

The approved V3-023 R2 scope identifies V3-017 reference
services as evaluation-only dependencies.

Two separate reference deployments exist:

- `deployment/shared/compose.yaml` uses V3-017 Spring Boot
  reference services.
- `deployment/shared/compose-routing-reference.yaml` uses
  the V3-023 synthetic Java routing Gateway and Cell Peers.

The V3-023 routing fixture demonstrates synthetic
two-Tenant routing, cross-Cell denial, fail-closed
forwarding, selected network segmentation tests and
reproducible Docker lifecycle behavior.

Direct runtime integration between the two reference
deployments has not been demonstrated.

## 2. Decision

Option A — Separate Evaluation Deployments is APPROVED.

For Stage B1, V3-017 serves as an evaluation-only
architectural reference.

The V3-017 and V3-023 reference deployments may remain
independent.

Direct runtime integration with V3-017 is not required
for the B1-F05 architecture dependency interpretation.

No additional integration implementation is authorized
or required by this decision.

## 3. Rationale

The R2 decision authorizes a synthetic REFERENCE_ONLY
implementation and identifies V3-017 as an evaluation-only
dependency.

It does not explicitly require both reference deployments
to execute within one Docker Compose stack.

The independent implementations preserve the narrow
testing purposes of V3-017 and V3-023 without treating
proposed V3-017 contracts as accepted baselines.

## 4. Consequences

- Separate deployments are accepted for the B1-F05
  architecture dependency interpretation.
- Direct V3-017 runtime integration remains unproven.
- V3-017 Formal R1 Acceptance remains PENDING.
- The B1-F05 architecture-owner decision is recorded.
- Independent review of this decision remains PENDING.
- No production identity or Tenant isolation is proven.
- PostgreSQL RLS and production readiness remain unproven.
