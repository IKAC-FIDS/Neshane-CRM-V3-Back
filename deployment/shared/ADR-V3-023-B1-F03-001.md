# ADR-V3-023-B1-F03-001 — Bounded Reference Readiness Verification

**Status:** APPROVED — ARCHITECTURE DECISION ONLY
**Decision date:** 2026-11-06
**Decision authority:** Technical Architecture Owner
**Scope:** V3-023 / Stage B1 / REFERENCE_ONLY
**Related finding:** B1-F03
**Implementation baseline:** ae232bb

## 1. Context

The V3-023 reference Docker deployment uses Compose
depends_on for startup ordering.

Application-level HTTP readiness healthchecks are
not configured in the routing Compose.

Recorded Docker lifecycle evidence confirms successful
startup, cleanup and HTTP verification using bounded retries.

Following restart:
- POST /tenant-a returned 200 cell-a-ok on attempt 2.
- POST /tenant-b returned 200 cell-b-ok on attempt 1.

Immediate readiness after container creation has not
been established.

## 2. Decision

Option A — Bounded Readiness Verification is APPROVED.

For the disposable REFERENCE_ONLY Stage B1 environment,
the recorded bounded HTTP readiness retry procedure
is accepted as sufficient engineering readiness evidence.

An additional Docker Compose application healthcheck
is not mandatory for the B1-F03 architecture disposition.

No modification to Docker Compose or Java runtime
is required by this decision.

## 3. Rationale

The approved Stage B1 scope is a disposable synthetic
routing demonstration, not a production deployment.

Bounded retries have demonstrated service readiness
after startup without claiming immediate availability.

The recorded lifecycle verification establishes
reproducible operation for the tested conditions.

## 4. Conditions and Limitations

- Bounded HTTP readiness verification must remain documented.
- Compose depends_on alone is not an application readiness guarantee.
- The decision does not establish immediate readiness.
- The decision does not establish production availability.
- No production health, orchestration or SLA guarantee is implied.
- Independent reviewer assessment remains pending.
- Reconsider the approach if the authorized scope changes.

## 5. Finding Disposition

B1-F03 architecture-owner decision: APPROVED — OPTION A.

Independent reviewer disposition: PENDING.

This decision addresses the architecture-level readiness
requirement for the reference deployment only.
